# SIM

Мобильная браузерная игра. Статический сайт: один `index.html`, без сборки и зависимостей.

## Файлы
- `index.html` — вся игра
- `vercel.json` — заголовки и кэш (HTML всегда свежий, чтобы патчи доходили сразу)
- `manifest.webmanifest`, `icon-*.png` — установка на экран «Домой», только вертикально
- `robots.txt`, `package.json`, `.gitignore`

## Деплой на Vercel
1. Залей файлы в репозиторий GitHub (или положи `sim-game.zip` и включи workflow `unpack-zip.yml`).
2. На vercel.com: Add New → Project → выбери репозиторий.
3. Framework Preset: Other. Build Command и Output Directory оставь пустыми. Deploy.

## Обновления
Замени файлы (или залей новый zip). Vercel сам пересоберёт сайт.

## Сохранения игроков
Прогресс лежит в localStorage браузера на их устройстве. Он переживает патчи, пока адрес сайта (домен) тот же.
Не меняй домен и ключ `sim1` в коде без миграции. Игра сама добавляет недостающие поля в старые сохранения.
